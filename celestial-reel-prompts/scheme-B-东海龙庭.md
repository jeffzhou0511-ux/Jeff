# 方案二：东海龙庭 · 潮生月府

> **一句话概念**：云海与潮海在天界交界，龙族仙府随月潮呼吸——把原片的"云"替换为"水"，保留仙宫骨架，得到一座可听潮、可放灯、可照月的水中天庭。
> **与原片的差异点**：青绿水色系（原片金白）、镜面水叙事占主导、渡舟/水灯/潮阶等水态道具、无源瀑布升级为"龙门跃瀑"。
> **总时长**：5 镜 × 5s = 25s ｜ 9:16 ｜ 情绪线：幽 → 静 → 缓 → 昂 → 阔

## 全局锁定

- **配色**：龙庭青玉 `#1E5E63` + 珍珠白 `#F2EFE6` + 灯暖金 `#E6B35C`（灯笼与窗光）
- **光线**：满月冷白主光 + 水下/雾中折射光斑 + 暖灯笼对冲；全片光向统一为正前偏上
- **角色锚点**：一名龙族女官，珍珠白交领广袖衫、石青披帛、发簪水滴玉坠、赤足踏玉阶（全片唯一人物，5 镜同款）
- **关键道具**：莲形水灯、白玉渡舟、青铜潮牌（记潮竹签）
- **主奇观配额**：呼吸月潮（贯穿但每镜形态不同）、月池镜宫、龙门瀑布、月洞潮门
- **雅事**：放水灯 → 掬水 → 立舟渡廊 → 仰观跃瀑 → 迎风拱手（5 种不重复）
