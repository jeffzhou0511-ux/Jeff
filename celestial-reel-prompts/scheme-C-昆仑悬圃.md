# 方案三：昆仑悬圃 · 霜松工坊

> **一句话概念**：昆仑之虚，悬圃凌空——古松不是庭院绿化而是建筑本身，仙宫是校星、铸器、养鹤的工坊群；用秋日琥珀色把原片的"恢弘天庭"落成有手作温度的"仙人日常"。
> **与原片的差异点**：暖琥珀+松绿的秋日配色（原片金白/月色）、建筑与古松共生结构、青铜工坊与声学长廊等"生活系统"空间、人物雅事密度最高（5 镜 5 事）。
> **总时长**：5 镜 × 5s = 25s ｜ 9:16 ｜ 情绪线：暖 → 专 → 柔 → 沉 → 远

## 全局锁定

- **配色**：琥珀金 `#C98A3B` + 霜白 `#F4EFE4` + 松绿 `#2E4A3A`，朱砂红仅作檐下小面积点缀
- **光线**：低角度秋日暖阳（黄金时刻偏暖橙）+ 松间丁达尔光束；全片光向统一为右侧逆光
- **角色锚点**：一名匠人仙卿，霜白交领深衣外罩松绿半臂、束袖革带、腰悬玉具小刀、木簪束发（全片唯一人物，5 镜同款）
- **关键道具**：煮茶风炉、青玉星册与玉质星盘、素铜钟与拓包、七弦琴、喂鹤的松实
- **主奇观配额**：松构一体大殿、悬空铸星井、蟠桃花庭、沉钟回廊、孤峰倒悬星河
- **雅事**：煮茶 → 校星册 → 喂白鹤 → 拓钟纹 → 抚琴（5 种不重复，覆盖品茗/工巧/自然相处/礼制/乐）
